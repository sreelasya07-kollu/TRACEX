# Docs map: who owns which fact

Each fact has exactly one owning file. Other files link to it and never copy it.
If two files disagree, the owning file wins and the other one is a bug (add a TODO row in
[04-TASKS](04-TASKS.md)).

## Fact-ownership map
| Fact | Owning file | Who edits it, when |
|---|---|---|
| Scope (core features, non-goals, constraints) | [00-PROJECT-CHARTER.md](00-PROJECT-CHARTER.md) (until locked: [charter-draft.md](charter-draft.md)) + approved [amendments/](amendments/) | owner only; locked once, never relocked |
| Scope change proposals | [change-requests/](change-requests/) `CR-NNN-*.md` | anyone proposes (`/change-request`); owner approves |
| Approved scope changes | [amendments/](amendments/) `AMD-NNN-*.md` | owner, after approving a CR |
| Tools: what / why / how | [01-TECH-STACK.md](01-TECH-STACK.md) | main session in `/end-session`, after an ADR |
| Pinned versions | `pyproject.toml` (constraints), `uv.lock` (resolved) | coder, in a brief with an ADR step |
| Licences (models, tools, datasets) | [MODELS.md](MODELS.md) | coder, in the brief that adds the model/tool |
| Module layout and boundaries | [02-ARCHITECTURE.md](02-ARCHITECTURE.md); rule text [INTERFACES.md §9](INTERFACES.md), enforced by `tests/test_module_boundaries.py` | main session in `/end-session`; boundary changes in the brief that changes them |
| On-disk formats, conventions, CLI flags | [INTERFACES.md](INTERFACES.md), [SCAN_BUNDLE.md](SCAN_BUNDLE.md), models in `formats/`, schemas in `spec/` | coder, same commit as the format change |
| Phase list, current phase | [03-PHASES.md](03-PHASES.md) | owner |
| Phase status and evidence | [PROGRESS.md](../PROGRESS.md) | main session in `/end-session` |
| Acceptance thresholds (PROPOSED) | [HANDOFF.md §5](../HANDOFF.md) | owner; change only with a written reason in the phase report |
| Owner rules for the code | [HANDOFF.md §2](../HANDOFF.md) | owner |
| Measured numbers per phase | `runs/test_results/` -> [PHASE_REPORTS/](PHASE_REPORTS/) (generated by `scripts/render_phase_reports.py`) | generated; never hand-edited |
| Heavy / GPU work items | [heavy-compute/inventory.yaml](heavy-compute/inventory.yaml) -> [INVENTORY.md](heavy-compute/INVENTORY.md) (generated) | coder edits the YAML |
| Tasks and their status | [04-TASKS.md](04-TASKS.md) | main session: claim on brief OK, DONE at commit; anyone adds TODO rows |
| Git, code style, definition of done, agent workflow | [05-CONVENTIONS.md](05-CONVENTIONS.md) | main session in `/end-session` |
| Decisions from 2026-11-17 on | [decisions/](decisions/) `NNN-*.md` | proposer (`/new-decision`); owner accepts |
| Decisions before 2026-11-17 | PROGRESS.md "Decisions and findings log" | frozen record, no backfill |
| Session history | [handoff/](handoff/) one file per session | main session in `/end-session` |
| Historical plan | [PLAN.md](PLAN.md) (frozen 2026-11-14; open items moved to 04-TASKS) | nobody |
| Original program specs | [specs/](specs/) | nobody (source material) |

## Read order for a new session
1. Charter (or the draft), 2. [04-TASKS](04-TASKS.md), 3. the current-phase section of
[03-PHASES](03-PHASES.md), 4. the newest two files in [handoff/](handoff/).
Everything else is read on demand (see the table in the root `CLAUDE.md`).
