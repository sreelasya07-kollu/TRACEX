# Handoff entries

One NEW file per working session, written by `/end-session`. Never edit an existing file.
Name: `YYYY-MM-DD-HHMM-<who>.md` (sorts by time; newest = last in the list).
Copy `_TEMPLATE.md`. `/start-session` reads the newest two.

Before 2026-11-17 the session history is in PROGRESS.md and HANDOFF.md (not backfilled).
